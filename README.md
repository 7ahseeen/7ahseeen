# About Me

I am a **Bioinformatics Engineering undergraduate** at **Bangladesh Agricultural University**, passionate about building software that helps solve biological problems.

My interests lie at the intersection of **bioinformatics**, **computational biology**, **scientific software engineering**, **artificial intelligence**, and **automation**. I enjoy transforming biological data into reproducible computational workflows and building practical tools for researchers.

### 🧬 Indentrix

**Local Biological Sequence Alignment Desktop Application**

A lightweight desktop application for local biological sequence alignment using Biopython. Designed for privacy-conscious analysis by performing sequence comparisons entirely on the user's machine without relying on external web services.

**Highlights**

* Local FASTA-based sequence alignment
* Thread-safe asynchronous processing
* Desktop-first scientific workflow
* Privacy-focused genomic analysis

**Tech Stack**

`Python` `Biopython` `Tkinter` `FASTA`

**Status**

🟢 Stable

---

### 🧬 GeneLens

**Gene & Protein Information Explorer**

Desktop software that integrates NCBI and UniProt APIs to retrieve, organize, and visualize biological information from multiple public databases through a unified interface.

**Highlights**

* Multi-database querying
* Batch gene/protein lookup
* Structured biological data presentation
* Exportable reports
* Live progress tracking

**Tech Stack**

`Java` `NCBI API` `UniProt API` `JSON`

**Status**

🟢 Stable
